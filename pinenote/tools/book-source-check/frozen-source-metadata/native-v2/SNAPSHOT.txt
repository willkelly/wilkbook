Identity model
==============

PACKET-ROSTER.txt is the exact file roster.  SOURCE-IDENTITIES.sha256 binds all
accepted and candidate executable project sources.  MANIFEST.sha256 binds every
file except itself; the outer repository runner hard-codes all three manifest
identities.  It copies this tree into a private 0500/0400 execution tree, invokes
the authenticated structural/source verifier there, and only then enters the
pinned Guix shell.  Expected source hashes and source directories are not caller
arguments or environment overrides.

Python runs under -I -S through an exact-path loader which checks and reports the
codec identity.  Project Scheme modules compile from this tree to one private
cache; the test checks those runtime compiled origins.  Mutation tests cover the
Python codec, blocking-I/O helper, a hash manifest changed to bless changed code,
an unlisted shadow module, legacy caller source/hash variables, and an extra
expected-hash argument.  Every mutation must reject before its execution canary.

NI-2 execution
==============

The existing two-language scenarios remain positive acknowledged receipt replay.
A separate Guile book sends one ordinary commit.  The test-only RUN-OPERATION
wrapper calls the real accepted adapter, then pauses before returning the result
to the delegate worker.  The endpoint closes while paused; the book must exit on
EOF without parsing state-committed and outbound frames remain zero.  An external
read-only SQLite connection observes version 1 plus one receipt before releasing
the callback.  A fresh authority/book load the value and retry the exact
operation ID/expected version, receive the original receipt, and leave value,
version, and receipt count unchanged.  A book which really consumes the receipt
and only then pretends loss is executed and rejected by the semantic oracle.

Execution and exclusions
========================

From the repository root:

  make -C pinenote/tools/book-state-integration check

Expected coverage is 13 retained focused factory assertions, six retained
normal/boundary authority phases with twelve Guile/Python books, three additional
lost/retry/counterexample authority phases with three Guile books, exact module
origins, six source mutation counterexamples, and the mandatory 4,096-byte NUL
round trip.  Counts may increase only with explicit new coverage; v1's old counts
are not used as a v2 success oracle.

This is bounded native host Guile/Python/SQLite evidence only.  It does not use
QEMU, runsc, ARM, KOReader, an image, kernel, mount, device, staging, commit, or
push.  The accepted 45-path sandbox closure is checked unchanged, but the native
execution is not claimed to be sandboxed.

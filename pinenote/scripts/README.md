# PineNote Scripts

Runtime helper scripts are generated by Guix packages for now:

- `pinenote-firmware-support` installs `pinenote-install-waveform` and the
  `rockchip_ebc` module option reference.
- `pinenote-diagnostics` installs `pinenote-diagnostics`.
- `pinenote-ebc-test` installs a default read-only EBC report and an explicit
  reversible framebuffer smoke test.

Preflight scripts in `pinenote/scripts/preflight/` stage, extract, and inspect
local fixtures only. They must not alter storage layout, bootloader state, or
device contents. The rootfs helpers operate on host-side image files: extract
the single ext4 partition from Guix's raw image intermediate, label it
`PNGuixRoot`, normalize the embedded extlinux root argument, reject artifacts
that still look like partitioned disks, and stage a rootfs-matched boot bundle
from the same image.

For USB-C-only PineNote bring-up, use the `pinenote-usb-console` system flavor;
it adds a CDC-ACM gadget plus a `ttyGS0` getty and passwordless `sudo` for
`reader` so the host can operate a boot that reaches Shepherd without Wi-Fi or a
physical keyboard.

Keep this directory for future source scripts when helpers outgrow inline
`trivial-build-system` builders. Scripts in this repository must remain
build-only or first-boot local actions and must not alter storage layout or
persistent boot selection.

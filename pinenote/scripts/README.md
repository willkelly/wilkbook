# PineNote Scripts

Runtime helper scripts are generated by Guix packages for now:

- `pinenote-firmware-support` installs `pinenote-install-waveform` and the
  `rockchip_ebc` module option reference.
- `pinenote-diagnostics` installs `pinenote-diagnostics`.
- `pinenote-ebc-test` installs the first read-only EBC test placeholder.

Preflight scripts in `pinenote/scripts/preflight/` stage and inspect local
fixtures only. They must not alter storage layout, bootloader state, or device
contents.

Keep this directory for future source scripts when helpers outgrow inline
`trivial-build-system` builders. Scripts in this repository must remain
build-only or first-boot local actions and must not alter storage layout or
persistent boot selection.
